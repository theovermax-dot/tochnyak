# Точняк

Telegram Mini App: угадай счёт матчей топ-7 лиг, копи ауру и поднимайся в рейтинге. Без ставок и денег.

Работает целиком на бесплатном Cloudflare: один Worker раздаёт приложение, отвечает на API и боту, база D1 хранит игроков и прогнозы, расписание раз в 10 минут забирает матчи с football-data.org и начисляет ауру.

## Что внутри

| Путь | Что это |
|---|---|
| `src/index.js` | Worker: API, вебхук бота, разовая настройка `/setup`, расписание |
| `src/telegram.js` | Вход через Telegram: проверка подписи initData |
| `src/scoring.js` | Правила начисления ауры |
| `src/footballData.js` | Загрузка матчей и подсчёт ауры после финала |
| `src/db.js` | Схема базы (создаётся сама при первом запросе) |
| `public/` | Мини-апп, политика конфиденциальности и правила |
| `test/` | Тесты: `npm test` (нужен Node 22+) |

## Запуск в Cloudflare (один раз)

1. **База.** Cloudflare → Storage & Databases → D1 → Create → имя `tochnyak`. Database ID прописан в `wrangler.jsonc`.
2. **Worker из GitHub.** Workers & Pages → Create → Import a repository → выбери `tochnyak`. Команды оставь по умолчанию (`npx wrangler deploy`).
3. **Секреты.** Worker → Settings → Variables and Secrets → Add, тип Secret:
   - `BOT_TOKEN` — токен бота из BotFather;
   - `FOOTBALL_DATA_TOKEN` — токен football-data.org;
   - `WEBHOOK_SECRET` — любая длинная случайная строка из латиницы и цифр (например, 40 символов).
4. **Настройка бота.** Открой в браузере `https://<адрес-воркера>/setup?key=<WEBHOOK_SECRET>`. Должно прийти `"ok": true`. Это подключит бота к Worker, поставит кнопку «Играть» и сразу загрузит матчи.
5. **Проверка.** Напиши боту `/start` и нажми «Открыть Точняк». Состояние синхронизации видно по адресу `/health`.

Секреты в репозиторий и в чаты не отправляем никогда.

## Правила ауры

Точный счёт 10, разница мячей 6, исход 3. Бонусы: «обе забьют» +1, тотал 2,5 +1. Редкий исход (меньше 10% игроков) удваивает основу, 10–25% даёт ×1,5, если на матч есть хотя бы 20 прогнозов. Менять в `src/scoring.js`.
